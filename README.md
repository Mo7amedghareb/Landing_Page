# Solar Energy Landing Page

A modern and responsive landing page for a solar energy company, built with HTML and CSS. The project focuses on clean layouts, responsive design, and presenting renewable energy services in a professional way.

## Features

- Responsive Design
- Hero Section
- Services Section
- About Section
- Customer Testimonials
- Call-to-Action Section
- Clean and Modern UI

## Technologies

- HTML5
- CSS3

## Purpose

This project was developed as part of the Webmaster Frontend Training to practice responsive web design, semantic HTML, and CSS layout techniques.
